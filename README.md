# Solar Forecast App

A Flutter app that visualizes monthly solar power forecast data as an interactive bar chart — the final "view" layer in a three-part pipeline that goes from raw API data to something a user can actually read.

## What it does

Loads a bundled JSON file (`assets/solar_forecast.json`) containing 12 months of forecasted AC power output for a solar installation in Bangkok, and renders it as a bar chart using `fl_chart` — one bar per month, labeled with month names on the x-axis.

## How it fits with the other projects

This app is the last stage of a 3-part pipeline:

```
Solar Data ETL Pipeline  →  solar_forecast.json  →  Solar Forecast App (this repo)
   (API → SQLite → S3)         (exported data)          (Flutter chart)
```

The JSON file consumed here is generated by the [Solar Data ETL Pipeline](../solar-etl-pipeline), which pulls monthly forecast data from the NREL PVWatts API. Right now the app reads a static copy of that JSON bundled as a Flutter asset; the data isn't pulled live from the pipeline's output.

## Setup

1. `flutter pub get`
2. Make sure `assets/solar_forecast.json` is present and declared under `flutter: assets:` in `pubspec.yaml`
3. `flutter run`

## What I'd improve next

- Pull `solar_forecast.json` from the pipeline's AWS S3 bucket at runtime (`https://<bucket>.s3.<region>.amazonaws.com/solar_forecast/<date>.csv`) instead of bundling a static copy, so the chart always reflects the latest pipeline run instead of whatever was bundled at build time
- Add a pull-to-refresh gesture to trigger that fetch
